# ChromeToolbox

实用的网页工具集合。

## 功能

### 查看密码
扫描当前页面所有密码输入框，直接将 `type="password"` 改为 `type="text"`，直接在原位置显示密码内容。

### 修改 Header
基于 Chrome `declarativeNetRequest` 动态规则修改网络请求的 HTTP 头：

- 支持**请求头**和**响应头**，操作包括「设置(set)」「追加(append)」「删除(remove)」，规则行采用 `Key = Value` 布局
- 支持**多个分组**：左侧边栏以**单字头像**列出全部分组（默认取分组名称首字，也可为每个分组设置一个字的**简称**），头像角标显示规则条数，圆形 `＋` 钮新建、悬停头像点 `×` 删除；空分组删除无需确认，空分组最多保留 3 个；每个分组有独立的规则列表
- **总开关**位于外层「修改 Header」卡片右侧（面板右上角也有一个，状态同步），旁边显示当前生效分组的简称头像；一键停用/启用全部 Header 修改，停用时不发送任何修改但规则与分组均保留
- 每条规则可填写**备注**（仅本地记录，不会随请求发送）
- 每个分组可单独设置**组级 URL 过滤**（如 `||example.com`），对组内全部规则生效，留空则对所有网站生效
- **输入自动保存**：分组名称、简称、URL 过滤、规则的 Key/Value/备注等所有编辑停顿约 0.5 秒即自动保存并生效，无需任何「应用」按钮；总开关开启时点击左侧头像立即切换为该组的 Header；正在填写 Value 的行会暂不生效且不打扰
- 全部分组配置持久保存，重启浏览器不丢失；旧版单组配置会自动迁移，按原 URL 过滤自动归并成分组

URL 过滤使用 Chrome [urlFilter 语法](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest#property-RuleCondition-urlFilter)，例如：

- `||example.com`：匹配 example.com 及其所有子域名
- `*://*.example.com/*`：匹配 example.com 子域名下的 http/https 请求

### 识别二维码

基于 jsQR 识别网页中的二维码（支持 `img` 图片和 `canvas`）：

- **右键菜单**：在网页中右键 →「识别二维码」，右键目标是图片则直接识别，否则进入选择模式
- **扩展按钮**：点扩展图标 →「识别二维码」，页面变暗后点击要识别的二维码
- 识别结果弹窗展示内容，链接可一键打开，支持 ESC 关闭

### 图片预览

在**任意网页**直接在当前页弹出浮层查看大图，不再跳转离开页面：

- **多种打开方式**（与链接资源预览共用同一设置，六种任选）：直接点击（默认）、`Alt` + 点击、右键图片 →「预览图片」、按住拖开约 12px 后松手打开（圆环填实提示就绪，未拖够距离松手按普通点击处理）、长按（时长可调，显示进度环）、悬停（延时可调，显示进度环）
- **左右切换**：工具栏 `‹ ›` 或键盘 `← →`，在页面全部图片间循环浏览
- **放大缩小**：工具栏 `+ −`、鼠标滚轮或键盘 `+`/`-`，缩放时鼠标位置的图片内容会直接移到画面中心，无需先放大再拖动；放大后按住可拖动平移，图片四边都能拖到（鼠标贴近视口边缘时会自动持续平移），点「适应」或按 `0` 回到窗口适配
- **左侧缩略图栏**：默认单列显示、缩略图完整居中不裁切，点头部按钮可展开为三列；失效图片显示占位图标且仍可点击
- 工具栏支持**复制原图地址**（一键复制，成功有勾选反馈）、**查看原图地址**（展开完整地址条，可手动选中）、**定位到原图位置**（关闭浮层并平滑滚动到页面上的原图，红色高亮闪烁）、**跳转到仓库目录**（支持 GitHub、GitLab、Gitee、Bitbucket，按原生方式在当前页跳到图片所在目录）**下载图片**（下载本张、勾选指定图片或下载全部；勾选模式下点缩略图仍可预览，点右上角圆圈才选中，自动补全扩展名，显示进度）和**在新标签页打开**原图
- 按 ESC、点击空白处或右上角 `×` 关闭
- 表情图片、按钮/表单内的功能图标（小于 24px）不会被拦截；图片本身挂了自定义链接（`[![](图片)](链接)`）时，仍按原链接跳转
- 中键或 Ctrl/⌘+点击（新开标签）保持浏览器原生行为

功能默认全站自动生效，与 Markdown 预览共用扩展弹窗中的「资源预览」总开关（一键停用全部就地预览），点击该卡片即进入详细设置（开关在卡片右侧，点击开关不会进入）：

- **打开方式**：直接打开 / Alt+点击 / 右键菜单 / 拖动打开 / 长按打开（时长可调、显示进度环）/ 悬停打开（延时可调、显示进度环），六种模式任选，图片与 Markdown、PDF、音视频、文本代码链接共用一套设置
- **预览类型**：图片、Markdown、PDF、音视频、文本代码可分别启停，默认全部开启；停用某类型后对应图片或链接完全恢复浏览器原生行为，正在显示的该类型浮层会立即关闭
- **名单模式**：黑名单（默认，排除指定网站）或白名单（仅在指定网站生效），可随时切换；名单对图片、Markdown 等全部预览类型同时生效
- **添加网站**：一键加入/移除当前网站，也可手动输入域名或粘贴完整网址（自动提取域名）；按主机名精确匹配，已添加的网站可随时移除，设置自动保存

### 资源预览（Markdown / PDF / 音视频 / 文本代码）

在**任意网页**点击指向可预览文件的链接时，不跳转离开当前页，直接在页内浮层查看。与图片预览共用同一个总开关和网站名单：

- **Markdown**（`.md` / `.markdown`）：后台抓取原文（绕过跨域限制、携带登录 Cookie），marked 渲染 GFM 语法（标题、列表、表格、围栏代码块、删除线、任务列表等），渲染前经 DOMPurify 消毒，文档中的恶意脚本不会执行；文档内的相对链接、图片按文档地址自动解析，相对 `.md` 或其他支持类型的链接在同一浮层中继续浏览，同页 `#锚点` 保持原生滚动；直接访问 Markdown 文本地址（如 `raw.githubusercontent.com` 的 `text/plain` 页面）也会自动浮层
- **PDF**（`.pdf`）：浮层内嵌浏览器原生 PDF 查看器，可翻页、缩放、下载，不离开当前页
- **音频 / 视频**（`.mp3` / `.wav` / `.ogg` / `.flac` / `.mp4` / `.webm` 等）：浮层内 HTML5 播放器直接播放，加载失败时提示原因并可新标签页打开
- **文本 / 代码 / JSON**（`.txt` / `.json` / `.log` / `.yml` / `.xml` / `.csv` 以及 `.js` / `.py` / `.java` 等常见源码后缀）：等宽字体展示，`.json` 自动美化缩进，非法 JSON 按原文显示；超过 10MB 停止预览
- GitHub、Gitee、GitLab（含自建）、Bitbucket 上 Markdown/代码文件的 blob 页面链接自动换算为 raw 原文地址；抓取到的是 HTML 页面而非原文时提示并提供新标签页打开
- 顶栏显示文件名，支持**复制地址**（一键复制，成功有勾选反馈）和**在新标签页打开**；加载中转圈，地址失效显示 HTTP 状态与兜底按钮
- **六种打开方式**（设置页可选，图片与 Markdown / PDF / 音视频 / 文本代码链接共用）：
  - **直接打开**（默认）：左键点击可预览链接即弹出浮层
  - **Alt + 点击**：按住 `Alt` 点击才预览，普通点击保持浏览器原生跳转
  - **右键菜单**：右键链接 →「预览链接」，左键点击完全不拦截
  - **拖动打开**：按住链接向任意方向拖开约 12px（圆环填实）后**松手才打开**；未拖够距离松手按普通点击处理，保持浏览器原生行为
  - **长按打开**：按住链接达到设定时长即预览，长按期间光标处显示进度环，时长可在 200–3000ms 间设置（默认 500ms）；普通点击保持原生
  - **悬停打开**：悬停链接达到设定时长自动预览，光标处显示进度环，移开即取消，延时可在 200–3000ms 间设置（默认 600ms）；关闭浮层后短时间内不会因光标仍停在链接上而重弹
- 按 ESC、点击遮罩或右上角 `×` 关闭；中键、Ctrl/⌘ + 点击（新开标签）以及带 `download` 属性的链接在任何模式下都保持浏览器原生行为

功能默认全站自动生效，与图片预览共用扩展弹窗中的「资源预览」总开关、同一套打开方式和网站名单（黑名单/白名单对全部预览类型同时生效），后续可继续扩展更多链接类型。

## 安装方法

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件夹

## 使用方法

### 查看密码

1. 访问任意网页
2. 点击浏览器右上角的扩展图标
3. 点击「查看密码」按钮

### 修改 Header

1. 点击扩展图标，选择「修改 Header」
2. 卡片右侧的开关即为 Header **总开关**，开关左侧的单字头像是当前生效分组；直接点卡片进入编辑
3. 在左侧边栏选择头像分组（或点「＋ 新建分组」），在右侧填写分组名称、单字简称（选填）和本组的 URL 过滤（选填）
4. 在组内设置请求头/响应头的 Key、Value（删除操作无需填值）
5. 总开关开启时点击左侧头像**立即切换生效**；规则、名称、URL 等输入停顿约 0.5 秒**自动保存并生效**，新发起的网络请求即携带修改后的 Header
6. 如需暂时停用，关闭外层卡片或面板右上角的总开关即可，规则与分组都会保留，重新开启即恢复生效

## 注意事项

- 查看密码仅在普通网页上可用，无法在 Chrome 内部页面（如 chrome://extensions/）使用；刷新页面后密码将恢复为隐藏状态
- 批量下载图片前，建议在 Chrome「设置 → 下载内容」中关闭「下载前询问每个文件的保存位置」，否则每张图片都会弹出一次保存确认；已失效的图片会计入失败数
- 修改 Header 对保存后**新发起**的请求生效，已完成的请求不会变化
- 受 Chrome 安全限制，部分头无法通过扩展修改（如请求头 `Cookie`、`Host`、`Sec-*`、`Proxy-*`，响应头 `Set-Cookie` 等），保存时对应行会显示浏览器的报错
- Header 修改为全局规则，不依赖扩展弹窗保持打开；总开关开启时同一时刻只有选中分组的规则生效，如需临时恢复默认 Header，关闭总开关即可（规则保留），或切到无规则的分组、删除规则
